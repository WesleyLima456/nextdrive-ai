# Roadmap - NextDrive AI

## Visão do projeto

Criar um funcionário virtual de marketing especializado em lojas de veículos.

O sistema deve transformar informações, fotos e vídeos de veículos em campanhas completas para redes sociais.

---

# Versão 0.1 - Fundação

Status: Em desenvolvimento

Objetivos:

- Criar estrutura inicial do projeto.
- Organizar documentação.
- Preparar integração com inteligência artificial.

---

# Versão 0.2 - Cadastro de veículos

Objetivos:

Criar uma área onde o usuário consiga cadastrar:

- Modelo.
- Ano.
- Versão.
- KM.
- Preço.
- FIPE.
- Opcionais.
- Observações.

Permitir envio de:

- Fotos.
- Vídeos.
