# NextDrive AI 🚗🤖

## Sobre o projeto

O NextDrive AI será um funcionário virtual de marketing especializado em lojas de veículos.

O objetivo é transformar fotos, vídeos e informações de um veículo em uma campanha completa de conteúdo para redes sociais.

## Objetivo principal

Permitir que uma loja de veículos consiga criar conteúdo profissional para Instagram de forma rápida utilizando inteligência artificial.

## O usuário fornece:

- Fotos do veículo
- Vídeos do veículo
- Informações do carro
- Preço
- Opcionais
- Características

## A inteligência artificial deverá gerar:

- Roteiros para Reels
- Legendas
- Stories
- Carrosséis
- Capas e thumbnails
- Ideias de conteúdo
- Campanhas de divulgação

## Visão futura

O sistema deverá evoluir para um funcionário de marketing completo capaz de:

- Criar vídeos automaticamente
- Criar artes
- Organizar campanhas
- Analisar resultados
- Sugerir melhorias
- Auxiliar na venda de veículos
